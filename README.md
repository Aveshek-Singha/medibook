# MediBook

MediBook is a clinic appointment platform with a NestJS API and a Next.js web app. It supports patient sessions, doctor discovery, appointment booking and changes, clinician availability, administrative controls, audit events, and SMS reminders.

## Project structure

- `api/` — NestJS API, database migrations, and API setup guide.
- `web/` — Next.js web application.
- `docker-compose.yml` — local MySQL and Redis services.
- `PRODUCTION_READINESS.md` — deployment and production-readiness notes.

For requirements and API setup, see [api/README.md](api/README.md).
